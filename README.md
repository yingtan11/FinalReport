# FinalReport

This project implements and compares the deterministic Bak–Tang–Wiesenfeld (BTW) 
sandpile model and the stochastic Manna model. 
Simulations are used to investigate the distributions of avalanche topples, area, 
loss, and length across different system sizes.

## Files

- `main.tex` — source for the final report.
- `python/sandpile.ipynb` — implementation, simulations analysis, and figure generation.
- `python/output/` — figures generated by the notebook.

## Requirements

The analysis was run using:
- Python 3.13.9
- NumPy 2.3.5
- pandas 2.3.3
- Matplotlib 3.10.6
- scikit-learn 1.7.2

## Running the code

1. Ensure the required packages are installed.
2. Open `sandpile.ipynb`.
3. Run the all notebook cells in order from top to bottom to reproduce results and figures.
4. Generated figures will be saved in the `output` directory.

The notebook runs separate simulations for the BTW and Manna models. 
The Manna simulations may take longer (approx 4 mins on an Apple M1 processor) because of their stochastic toppling rule.

## Reproducibility

Random-number seeds are specified in the notebook so that the simulations can be reproduced. 

## Analysis

The notebook includes:
- burn-in checks for both models;
- power-law analysis of topples;
- power-law analysis of area;
- exponential analysis of loss;
- power-law AND exponential analysis of length;
- correlations between avalanche properties.

Under each section of analysis for avalanche properties, results for BTW and Manna are compared.
